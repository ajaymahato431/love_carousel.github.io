# Love Carousel

## Introduction
Love Carousel is a visually engaging web project designed to showcase love-themed cards or slides in a dynamic carousel format. Built for a delightful user experience, it combines smooth transitions and attractive layouts to celebrate love and affection.

## Features
- Responsive carousel for love cards/slides
- Beautiful CSS animations and transitions
- Easy navigation with arrow controls (or auto-play)
- Customizable content for each card
- Lightweight and fast loading
- Works across devices (desktop and mobile)

## Tech Stack
- **HTML**: Structure of web pages and carousel items
- **CSS**: Styling, layouts, and animations
- **JavaScript**: Carousel logic (slide switching, transitions, controls)

## How to Use
1. **Clone or Download** the repository:
   ```sh
   git clone https://github.com/ajaymahato431/love_carousel.github.io.git
   ```
2. **Open `index.html`** in your browser. No installation required!
3. **Interact with the carousel**:
   - Use arrow buttons to move between cards
   - On mobile, swipe to navigate
   - Enjoy the animated slides!

## Customization
- Edit the HTML to add or change love cards/slides.
- Update CSS styles in `style.css` to match your theme.
- Modify JavaScript in `script.js` for advanced carousel controls.
